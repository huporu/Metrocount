# Composició

En el nostre projecte disposarem una base de dades, un servidor web, dos dominis diferents (Un per la part frontend i l'altre per gestionar de manera backend) i el hardware que utilitzarem per el metro seria multiples sensors infraroigos per cada porta del tren, adaptadors de xarxa del sensors porque es puguin connectar-se els repetidors wifi per despres enviar l'informació al servidor en la qual la base de dades recollira aquesta informació i ho mostrara al frontend.
